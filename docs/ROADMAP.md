# Public roadmap

This is a small, independently maintained library; priorities are proposals until validated with reproducible user feedback. Changes must not depend on PartnerMap's private production database.

## Released — v0.1.0

- [x] Standalone TypeScript search helpers, zero runtime dependencies
- [x] Turkish casing, spacing, diacritic and bounded typo-rescue tests
- [x] Input-length and caller-supplied candidate bounds
- [x] MIT license, security policy, contributor guide and GitHub Actions CI
- [x] Publish a clean public repository with passing CI
- [x] Tag and publish [`v0.1.0`](https://github.com/Nebride69/partnermap-search-core/releases/tag/v0.1.0)
- [x] Document verified first-party integration and public read-only examples
- [x] Add Turkish-language documentation and copyable examples

## Possible future work — based on authentic issues or contributions

- [ ] Benchmark a synthetic test corpus; document reproducible performance limits
- [ ] Evaluate ambiguous abbreviations, transliteration and punctuation, prioritizing false-positive avoidance
- [ ] Improve accessibility and documentation based on independent feedback
- [ ] Verify installation, provenance and semver policy before deciding whether to publish to npm
- [ ] Review external contributions and maintain a transparent release history as contributions arise

## Project integrity

The library's source is used in PartnerMap, but the **commercial website's user counts, directory records and traffic are not public library adoption statistics**. Do not invent downloads, stars, forks, issue reports or external maintainers to demonstrate activity.

For contributions, see [CONTRIBUTING.md](../CONTRIBUTING.md). For security reports, see [SECURITY.md](../SECURITY.md).
